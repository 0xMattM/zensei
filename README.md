# ZenSei - Ultimate Sei DeFAI Multi-Agent System

*Simplifying DeFi for everyone through intelligent automation*

## Overview

ZenSei is a revolutionary multi-agent system built for the Sei ecosystem that transforms complex DeFi operations into simple, natural conversations. Our **9 specialized AI agents** work in harmony to handle everything from portfolio management to contract deployment, making DeFi accessible to everyone.

## Meet Your AI Agents Team

### 🧘 **Zen Master** (Orchestrator Agent)
*The heart of ZenSei* - Coordinates all other agents and handles your natural language requests, deciding which specialized agents to activate for each task.

### 💰 **Wallet Sage** (Portfolio Agent)
Tracks your balances, portfolio performance, and 24h price changes across all your Sei assets.

### 📊 **Data Oracle** (Analytics Agent)
Provides comprehensive market data from DeFiLlama, CoinGecko, GeckoTerminal, and DexScreener.

### 🔄 **Transfer Guardian** (Wallet Agent)
Securely handles SEI and token transfers with built-in security measures and confirmations.

### 🌊 **DeFi Navigator** (DeFi Agent)
Interacts with top Sei protocols including Yei Finance, Symphony, DragonSwap, Silo, Takara, Citrex, and Carbon.

### 🔍 **Research Monk** (Research Agent)
Performs web research, finds news, and discovers new opportunities using Perplexity integration.

### 🗺️ **Chain Explorer** (Explorer Agent)
Provides real-time Sei Network data including transactions, blocks, balances, and contract information.

### 🏗️ **Contract Builder** (Deployer Agent)
Deploys ERC20 tokens, ERC721 NFTs, and custom smart contracts directly on Sei.

### 🎓 **Knowledge Keeper** (Expert Agent)
RAG-powered agent with comprehensive Sei ecosystem knowledge using Qdrant vector database.

- **Frontend**: TypeScript, Next.js, React

- **Blockchain**: Sei MCP Server
- **AI**: Multiple LLM providers with RAG capabilities
- **Database**: Qdrant vector database
