ZenSei is a revolutionary multi-agent system built for the Sei ecosystem that transforms complex DeFi operations into simple, natural conversations. Our **9 specialized AI agents** work in harmony to handle everything from portfolio management to contract deployment, making DeFi accessible to everyone.

## Quick Start

1. **Chat Naturally**: "Show me my portfolio performance this week"
2. **Execute DeFi**: "Swap 100 SEI for USDC on DragonSwap"
3. **Deploy Contracts**: "Create an NFT collection called 'Zen Warriors'"
4. **Get Insights**: "What are the trending DeFi protocols on Sei?"

## Key Features

- 🗣️ **Natural Language Interface** - Chat like you're talking to a friend
- 🤖 **9 Specialized Agents** - Each expert in their domain
- 🌐 **Web & Telegram Access** - Use anywhere, anytime
- 🔒 **Enterprise Security** - Your keys, your control
- ⚡ **Real-time Data** - Live prices, TVL, and analytics
- 🏗️ **Smart Contract Deployment** - Create tokens and NFTs effortlessly

## Tech Stack

- **Frontend**: TypeScript, Next.js, React
- **Agent Frameworks**: n8n, ElizaOS, Cambrian Agentic Framework
- **Blockchain**: Sei MCP Server
- **AI**: Multiple LLM providers with RAG capabilities
- **Database**: Qdrant vector database

## Integrations

**DeFi Protocols**: Yei Finance, Symphony, DragonSwap, Silo, Takara, Citrex, Carbon  
**Data Sources**: DeFiLlama, CoinGecko, GeckoTerminal, DexScreener  
**AI Services**: Perplexity, OpenAI, Claude, Gemini  
**Infrastructure**: Sei Network, Telegram Bot API
